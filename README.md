# Zay eCommerce Website — AWS & Docker Deployment

## Project Overview
This project involves deploying a static eCommerce website on an AWS EC2 instance using Docker and Nginx.

## Technologies Used
- AWS EC2
- Linux (Ubuntu)
- Docker
- Nginx
- HTML, CSS, JavaScript

## Architecture
User → Internet → AWS EC2 → Docker Container → Nginx → Website

## Implementation Steps
1. Launched an AWS EC2 instance.
2. Installed and configured Docker.
3. Prepared the website files.
4. Built a Docker image for the website.
5. Ran the website inside an Nginx container.
6. Configured network access through the EC2 security group.
7. Verified the website deployment.

## Key Learnings
- Deploying applications on AWS EC2
- Containerizing website deployments with Docker
- Hosting static websites with Nginx
- Configuring inbound traffic and troubleshooting connectivity

## Project Files
The original website ZIP file is included in this repository.

## Security
